# さす あそび 仕様（sasu-asobi）
出典：『認知発達治療の実践マニュアル』Stage I「6. 目と手の協応」6-1(1) 穴や棒にさす操作（p.39〜40、写真4 太さ比較棒・写真5 プラステン）。6-2（描く）、6-3（ハサミ・紙）は別アプリにする予定。
## 構成
- public/index.html + wrangler.jsonc（name sasu-asobi）。GitHub: hos-arch/sasu-asobi（ユーザーが作成予定）
## 遊び方
- 置き場（トレイ）の物を指で運び、合う穴・棒の上で離すと「ことん」と入る（音の高さは入れるたびに上がる、小さな星）
- 合わない所：上にのって0.45秒待ち、置き場へもどる。いやな音は出さない
- ぜんぶ入る：ベル3音＋星、物が順にぴょこっと動き、約3秒後に置き場へもどる（くり返し）
- 入った物は指でつまんで抜ける（棒の輪は一番上だけ。抜く間は棒にそって上へだけ動く）
## 場面と段階
- 円柱さし：大きさのちがう5つの穴（上から見た絵）。はずす数 1/3/5本（本の例：はじめは1本だけはずし、増やす）
- 棒にさす（プラステン）：棒 1/3/5本（容量5/3/2）。色 どれでも／色をそろえる（台座の色と同じ輪だけ）。横から見た絵
- ペグボード：穴 6/12/20、どの穴でもよい
- 太さくらべ：太さ 2/3/4種、左が細い。輪は合う太さの棒にだけ入る
## 支援者メニュー（右上の点を1.2秒長押し、案B）
- 場面（2×2）／この場面／みんな共通：手助け（大＝台の上のどこで離しても合う所へ／ふつう／小＝すぐ近くだけ）、置き場（利き手の側：右・左。横向きはトレイの左右、縦向きはトレイの寄せ）
- くわしく：場面の説明、触れ方、見た目、音、説明をもう一度／もとにもどす・とじる
## 本の留意点の反映
- 使わない手は大人が軽く押さえる、終わったらタイミングよく手を離させる → 説明画面に記載
- 利き手側に教材を呈示 → 置き場の左右設定
## 約束
- 子ども画面に文字なし。点滅なし。音はやわらかく音量上限。名前・記録・録音・顔を保存しない。治療効果をうたわない。
